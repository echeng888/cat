# Cat Illustration Project

This project demonstrates the use of **NumPy** and **Matplotlib** to create a custom vector-style illustration of a cat.

## Features
- **Mathematical Shapes**: Uses circles and ellipses generated via parametric equations.
- **Customizable**: Easy to modify colors and features directly in the code.
- **Modular Design**: Includes helper functions for geometric shapes that can be reused in other visualization projects.

## How to Use
1. Run the Python cell to generate the cat.
2. To change the cat's color, locate the `# --- Head ---` and `# --- Ears ---` sections in the code and update the hex color codes (currently `#9e9e9e`).

## Dependencies
- `numpy`
- `matplotlib`
